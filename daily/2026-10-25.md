### 20:50 认证启用后 autosync 断裂 —— 定位与修复
- 现象：云端启用认证后，两端 `cloud.json` 里的占位 token `lan-bridge-placeholder` 全部 401，19:00 后**再无成功同步**
- 第一层修复：把管理员 token 写入 cloud.json → 401 消失，转为 **403「project 家庭网络运维 is not allowed」**
- 根因：管理员 token 属 managed principal，需逐项目 grant；而 grant 的项目名经 `normalizeCloudProjectGrant` 归一化后只保留 `[a-z0-9._]` → **纯中文项目名归一化为空**，`POST /admin/users/1/grants` 恒定 400（"影视磁力助手movieget" 因含 ASCII 反而成功，正印证此点）
- 第二层修复：改用 compose 里的**服务级 `ENGRAM_CLOUD_TOKEN`**（非 managed principal，不走 grant）→ 两端 `家庭网络运维` 同步立即恢复（NAS 1 obs / PC 2 obs）
- 教训：项目若用纯中文名，在启用认证的 Engram Cloud 上**无法逐项目授权**，机器对机器同步应走服务级 token
- 凭证传递做法：NAS 起临时内网 HTTP 传递 token 给 PC，写入后立即 kill + 删除临时文件，token 不落地到对话/文档
