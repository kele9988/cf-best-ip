       │    ├─ Engram Cloud     :18081（云端记忆库，INSECURE 局域网模式 |

## 长期组件

- **cf_best 优选 IP 测速**：飞牛 `/root/cf_best/`，每天 0/4/8/12/16/20 点调度 slot 测速 → 池化淘汰 → 传 GitHub `kele9988/cf-best-ip` → Cloudflare DNS 按区更新
- **cf_ctrl 远程控制台**：飞牛 `:8777`，systemd `cf-ctrl.service`，MCP 端点 `http://192.168.2.5:8777/mcp`（局域网）/ `https://ssh.kele9988.top/mcp`（公网隧道，2026-10-25 实测 200，旧「公网不通」记录作废）
- **Tailscale**：fnOS 应用商店版 1.102.3，CLI 在 `/vol1/@appcenter/tailscale/bin/`（**不在 root PATH**），操作需 `--socket /vol1/@appdata/tailscale/tailscaled.sock`；fnnas=100.81.83.32
- **OpenClash**：运行时配置为 `/etc/openclash/kele9988_EDG.yaml`（非 `config/` 下那份），secret `ehappy9988`；策略组现状 `其他=所有-自动`、`Microsoft=直连`、`国外=台湾-故转`、`国内=直连`
- **Engram Cloud**：`http://192.168.2.5:18081`（宿主 18081→容器 18080；18080 被 wol-manager-arm 占用），卷 `engram-cloud-pg`，compose 在 `/root/engram-cloud/`
  - 认证已于 **2026-10-25 19:00 启用**：`ENGRAM_CLOUD_INSECURE_NO_AUTH=0` 关闭，`/dashboard` 强制登录；管理员 baichuan（principal_id=1）+ API token（`egc_live_*`）已签发
  - 凭证统一收口 `/root/engram-cloud/auth.env`（600）：`ENGRAM_JWT_SECRET` / `ENGRAM_CLOUD_TOKEN_PEPPER` / `ENGRAM_ADMIN_TOKEN`；`ENGRAM_CLOUD_TOKEN`（服务级）在 compose 内
  - 🔑 **客户端同步用 `ENGRAM_CLOUD_TOKEN`（服务级）而非管理员 token**：管理员 token 属 managed principal，需逐项目 grant，而 grant 项目名会被归一化成 `[a-z0-9._]`——**纯中文项目名（如「家庭网络运维」）归一化后为空，永远无法授权（400/403）**；服务级 token 不走 grant，可直接同步
  - 踩坑：bootstrap admin 须 `docker exec` 进容器执行（宿主机连不上 compose 内网 postgres）；`--issue-token` 前必须先配 `TOKEN_PEPPER`

## Engram 语义记忆栈（2026-10-25 建成）

| 层 | 地址 | 说明 |
|---|---|---|
| 云端记忆库 | `http://192.168.2.5:18081` | 权威存储，INSECURE 局域网模式 |
| MCP 桥 | `http://192.168.2.5:18082/mcp` | `engram-arm64 mcp --http --tools=agent --project=家庭网络运维`，autosync 双向 30s |
| Bearer 代理 | `http://192.168.2.5:18083` | `/root/engram-cloud/engram_proxy.py`，校验令牌后转发 |
| 公网端点 | `https://fnnas.tailc9fc92.ts.net:8443/mcp` | Tailscale Funnel，手机 5G / 云电脑沙箱通用 |

- 源码补丁在 NAS `/root/engram-cloud/src`（`main.go` 加 `--http`；`transport.go` 放行 HTTP+非空 token）
- PC 端 engram.exe 为自编译 3.6.0-http 补丁版（备份 `engram-old.exe`）
- 🔑 autosync **非常驻**：只在 `engram mcp`/`serve` 进程运行时活跃；PC 端依赖 WorkBuddy 的 engram MCP 连接器（重启后生效）
